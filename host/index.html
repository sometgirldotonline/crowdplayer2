Name your party

This name will be displayed to people when they connect, if you have more than one Crowdplayer at this party, consider naming them clearly.

Your files?

Please select your music folder. This may take a while the first time, so make sure you picked the right folder (make sure you didn't highlight a subfolder!). Crowdplayer accepts all common music file types
Examples: mp3, m4a, aac, wav, flac, ogg*, opus, webm
* no Ogg support on Apple Safari
